业务需求理解
建设目的：搭建溯源管理平台，构建自主可控的商品全链路数字化溯源管理能力，为集团内多主体、多销售平台提供统一、标准、可监管的数字化溯源服务；满足乡村振兴商品合规监管要求，支撑天虹超市商品溯源与品控管理，赋能乡村振兴商品供应商提升市场竞争力。
平台服务的四种业务场景
场景一
一期优先
集团子单位乡村振兴商品提报及溯源
各集团子公司（销售平台）在销售平台端提报需要溯源的乡村振兴商品；平台运营方（天虹）审核后派发检测任务；溯源机构回传报告；审核通过后生成中航溯源码，接入集团销售渠道展示。
场景二
乡村振兴赋能
天虹乡村振兴人员在种-产-销全链路各环节赋能帮扶供应商，在平台运管端结构化填写帮扶工作内容，形成汇总报告，向集团展示乡村振兴工作成果。
场景三
天虹自行监督
平台运营方（天虹）向天虹内部人员派发监督任务（选择溯源模板），供应商先填写基础信息与自检资料，天虹人员实地检查后在平台运管端回填结果、形成监督报告；报告除用于整改闭环外，回传供应链中台并纳入供应商评价体系的质量评分，不生成溯源码。
场景四
天虹超市商品溯源
天虹在销售平台端导入/填写需要溯源检查的超市商品；平台运营方（天虹）审核后，由供应商先填写检测信息与自检资料；溯源机构核对供应商预填内容并填写完整检测报告（支持无 API 机构人工录入）；审核通过后生成天虹溯源码，用于天虹 APP/小程序/超市线下展示。
主要角色说明
销售渠道
各集团子公司及天虹数科等销售平台，负责提报/导入需溯源的商品，接收溯源码并在自有渠道展示，面向消费者提供扫码验真入口。
天虹平台运营方
平台运营方（天虹）负责商品审核、任务派发、报告审核、溯源码生成及全链路数据监管，是连接各端的核心枢纽。
第三方检测机构
具备 CMA/CNAS 等资质的检测机构，接收检测任务后开展溯源检测，通过 API 或人工录入回传结构化检测报告。
商品生产 / 供货方
乡村振兴商品或超市商品的实际供应方，负责预填基础信息、上传自检资料、打印/粘贴溯源标签并配合现场检查。
天虹内部监督人员
接收天虹自行监督任务，依据溯源模板对供应商进行现场检查，回填监督结果并形成监督报告回传供应链中台。
消费者
通过天虹 APP/小程序、超市线下或集团销售渠道扫码，查看产品信息、企业信息与追溯信息，验证商品真伪与溯源链路。
集团视角
集团管理人员通过平台运管端查看各类检测/监督报告、乡村振兴商品清单与帮扶成果汇总，支撑管理决策与成果展示。
