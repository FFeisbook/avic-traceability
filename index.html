业务需求理解
基于政企规划流程图，梳理四大业务场景、关键角色及平台服务的全链路动作：乡村振兴商品溯源、超市商品溯源、天虹自行监督、乡村振兴赋能
建设目的：搭建溯源管理平台，构建自主可控的商品全链路数字化溯源管理能力，为集团内多主体、多销售平台提供统一、标准、可监管的数字化溯源服务；满足乡村振兴商品合规监管要求，支撑天虹超市商品溯源与品控管理，赋能乡村振兴商品供应商提升市场竞争力。
平台服务的四种业务场景
场景一
集团子单位乡村振兴商品提报及溯源
各集团子公司（销售平台）在销售平台端提报需要溯源的乡村振兴商品；平台运营方（天虹）审核后派发检测任务；检测机构回传报告；审核通过后生成中航溯源码，接入集团销售渠道展示。
场景二
天虹超市商品溯源
天虹在销售平台端导入/填写需要溯源检查的超市商品；平台运营方（天虹）审核后派发检测任务；检测机构回传报告；审核通过后生成天虹溯源码，用于天虹 APP/小程序/超市线下展示。
场景三
天虹自行监督
平台运营方（天虹）向天虹内部人员派发监督任务（选择检测模板），业务人员实地检查后在平台运管端回填结果，形成监督报告与结论，不生成溯源码。
场景四
乡村振兴赋能
天虹乡村振兴人员在种-产-销全链路各环节赋能帮扶供应商，在平台运管端结构化填写帮扶工作内容，形成汇总报告，向集团展示乡村振兴工作成果。
四大业务场景详细流程（角色 · 端 · 关键动作）
下表列出每种场景中，什么角色在什么端做哪些关键业务动作。
场景一：集团子单位乡村振兴商品提报及溯源（中航溯源）
角色操作端关键业务动作
各集团子公司
（销售平台）		销售平台端提报需要溯源的乡村振兴商品；维护商品与供应商档案；查看溯源进度与检测结果；下载/应用溯源码。
平台运营方
（天虹）		平台运管端审核提报商品；管理溯源及检查模板；向溯源机构派发检测任务（快检 / 定量 / 供应商工厂审核 / 虫害等）；审核检测报告；生成中航溯源码；管理物料打印。
溯源机构检测机构端接收任务；通过 API 对接按检测模板项目回传结构化检测报告；支持上传 PDF 报告。
供应商供应商端填写并提交企业/产地/生产等需要供应商维护的信息；配合整改；打印/粘贴溯源标签。
集团用户平台运管端查看各类乡村振兴工作报告（商品溯源进度、检测报告、赋能汇总等）。
场景二：天虹超市商品溯源（天虹溯源）
角色操作端关键业务动作
天虹销售平台端导入 / 填写需要溯源检查的超市商品；维护商品与供应商档案；查看检测结果；下载/应用天虹溯源码。
平台运营方
（天虹）		平台运管端审核提报商品；管理检测模板；向溯源机构派发检测任务（快检 / 定量 / 供应商工厂审核 / 虫害等）；审核检测报告；生成天虹溯源码；管理物料打印。
溯源机构检测机构端接收任务；通过 API 对接按检测模板项目回传结构化检测报告；支持上传 PDF 报告。
供应商供应商端填写并提交需要供应商维护的信息；配合整改；打印/粘贴溯源标签。
场景三：天虹自行监督
角色操作端关键业务动作
平台运营方
（天虹）		平台运管端向天虹内部人员派发监督任务（选择检测模板）；查看任务执行进度；审核回填结果；形成监督报告和结论。
天虹内部业务人员平台运管端
/ 移动端		接收监督任务；实地检查；按检测模板回填检查结果；提交监督报告。
供应商供应商端接收整改要求（如监督发现不合格）；提交整改资料。
说明：监督任务不生成溯源码，仅用于平台内部质量管控与报告归档。
场景四：乡村振兴赋能
角色操作端关键业务动作
天虹乡村振兴人员平台运管端在种-产-销全链路各环节赋能帮扶供应商；结构化填写帮扶工作内容（资质证件、生产操作合规、市场化能力、需求匹配、赋能建议）。
供应商供应商端 / 现场配合实地调研；提供资质与生产记录；接收赋能建议并整改。
集团用户平台运管端查看乡村振兴赋能汇总报告，了解天虹全链路帮扶乡村振兴企业的工作成果。

业务规则与状态机（已知要点 · 待 PRD 最终确认）
① 溯源商品状态机（平台运营端统一管理）
提报 → 审核中 → 已通过 / 已打回 → 上架 / 下架；打回后由提报方修改再提交。
② 溯源 / 检测任务状态机
平台派发 → 机构接收 → 检测中 → 待签章 → 已提交 → 平台审核报告 → 通过（生成溯源码） / 不通过（触发整改）。
③ 监督任务（与溯源任务区分）
由天虹向内部人员派发，按检测模板执行并回填结果，仅产出监督报告与结论，不生成溯源码。
④ 整改闭环
检测/监督不通过 → 供应商接收整改要求 → 提交整改资料 → 检测机构通过 API 回传复检报告 → 平台运营方审核 → 通过 / 再整改。
⑤ 溯源码规则
一物一码，绑定商品 + 检测报告；支持中航溯源与天虹溯源两种品牌标识；标签由平台通知打印、供应商粘贴发货；消费者扫码验真。
⑥ 检测报告接入
检测机构端不做逐项录入功能；检测机构通过标准 API 按检测模板项目回传结构化检测报告，同时支持上传 PDF 报告。
