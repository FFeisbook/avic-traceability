业务需求理解
建设目的：搭建溯源管理平台，构建自主可控的商品全链路数字化溯源管理能力，为集团内多主体、多销售平台提供统一、标准、可监管的数字化溯源服务；满足乡村振兴商品合规监管要求，支撑天虹超市商品溯源与品控管理，赋能乡村振兴商品供应商提升市场竞争力。
平台服务的四种业务场景
场景一
一期优先
集团子单位乡村振兴商品提报及溯源
各集团子公司（销售平台）在销售平台端提报需要溯源的乡村振兴商品；平台运营方（天虹）审核后派发检测任务；溯源机构回传报告；审核通过后生成中航溯源码，接入集团销售渠道展示。
场景二
一期优先
天虹超市商品溯源
天虹在销售平台端导入/填写需要溯源检查的超市商品；平台运营方（天虹）审核后，由供应商先填写检测信息与自检资料；溯源机构核对供应商预填内容并填写完整检测报告（支持无 API 机构人工录入）；审核通过后生成天虹溯源码，用于天虹 APP/小程序/超市线下展示。
场景三
天虹自行监督
平台运营方（天虹）向天虹内部人员派发监督任务（选择溯源模板），供应商先填写基础信息与自检资料，天虹人员实地检查后在平台运管端回填结果、形成监督报告；报告除用于整改闭环外，回传供应链中台并纳入供应商评价体系的质量评分，不生成溯源码。
场景四
乡村振兴赋能
天虹乡村振兴人员在种-产-销全链路各环节赋能帮扶供应商，在平台运管端结构化填写帮扶工作内容，形成汇总报告，向集团展示乡村振兴工作成果。

中远期前瞻需求 · 园地物联网实时溯源与溯源营销中远期 · 本期暂不做
当超市（如天虹）承包/合作一块园地（种植基地）时，可在园地部署物联网设备（摄像头、环境/土壤传感器、气象站等），将产地实时数据回传平台——消费者扫码即可查看产地实时信息，并支持溯源直播与溯源营销，进一步增强消费者信任与品牌溢价。
① 物联网设备部署
园地部署摄像头、环境/土壤传感器、气象站等，采集实时影像与产地环境数据。
② 实时数据回传
设备数据经 IoT 网关实时上传平台，绑定到具体产地、地块与商品批次。
③ 扫码看实时产地
消费者扫码除常规溯源信息外，还可查看产地实时画面（直播）与温湿度等环境数据。
④ 溯源直播 / 营销
基于产地摄像头做溯源直播或录播剪辑，用于品牌背书与内容营销，提升溢价。
说明：以上为中远期前瞻需求，一期（本期）暂不做。建议优先寻找已具备物联网硬件+软件解决方案的园区/基地，直接对接其摄像头、传感器等实时数据，降低自建 IoT 成本，快速实现产地实时信息展示与溯源直播。

主表间流转关系（逻辑 ERD）
销售平台 → 供应商创建即入库，平台级复用
供应商 → 商品档案1:N，供应商提供多个商品
商品档案 → 任务1:N，商品被派发多个检测任务
溯源模板 → 任务1:1，一个任务仅对应一个溯源模板
溯源机构 → 任务N:1，机构或天虹作执行方
任务 → 检测报告1:1，一个任务仅出一份完整检测报告
源头资料 → 报告补充，绑定供应商/商品
报告 → 溯源码N:1，多份报告汇总生成一个商品溯源码
溯源码 → 销售平台OpenAPI 推送溯源信息
销售平台 → 销售回传平台回传销量/扫码数据
说明：以上为原型阶段逻辑数据模型（实体与关系），用于对齐各端数据口径；落地时按实际选型（如关系库 + 一物一码引擎）细化字段、索引与一致性约束。
